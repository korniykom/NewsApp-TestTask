## Tech stack

| Layer | Library |
|---|---|
| UI | Jetpack Compose, Material 3 |
| Navigation | Navigation 3 |
| DI | Koin |
| Networking | Ktor Client |
| Local cache | Room |
| Pagination | Paging 3 |
| Image loading | Coil 3 |
